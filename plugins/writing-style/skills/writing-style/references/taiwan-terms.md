# 台灣用語對照表

主動過濾中國用語，改用台灣慣用語。此表列高頻對照；未列出的詞也依台灣慣用語判斷，不以此表為限。技術術語維持中英夾雜、不硬翻（Log、Endpoint、Sprint 等保留英文）。

## 高頻犯錯詞

各家 LLM 最常見的犯錯詞，交付前優先自檢：靜默、閾值、文檔、代碼、場景、根因、配置、日誌。
